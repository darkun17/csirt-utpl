# CSIRT UTPL - Prototipo Next.js + React

## Objetivo
Primer prototipo funcional, institucional y administrable para el sitio del CSIRT UTPL.

## Cómo ejecutar

```bash
npm install
npm run dev
```

Abrir:

```bash
http://localhost:3000
```

## Páginas incluidas
- `/` Home storytelling del CSIRT.
- `/alertas` Listado de alertas y recomendaciones.
- `/alertas/[slug]` Página de noticia/alerta administrable.
- `/reportar-incidente` Formulario simulado de reporte.
- `/rfc2350` Página formal de RFC2350.
- `/recursos` Centro de documentación, guías y enlaces.

## Componentes
Header, HeroSecurity, Pathways, AlertCard, LatestAlerts, Services, ResourceGrid, bloques administrables de enlaces, video, checklist y Footer.

## Colorimetría
Azul `#003F72`, amarillo `#EAAB00`, rojo `#A71930`, gris claro `#E0DED8`, gris medio `#7D7D7D`.
